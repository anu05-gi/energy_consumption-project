## Project Summary

This project analyzes the energy usage of  buildings using Excel and Power BI. It includes building data, energy consumption records, and energy rate sheets. The goal is to identify trends and calculate costs.

---

## Files

- `building_master.xlsx` –  building details  
- `energy_consumption_dataset.xlsx` – Usage data for 2023  
- `energy_rates.xlsx` – Energy rates
